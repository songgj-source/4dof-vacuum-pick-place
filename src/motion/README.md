# HOME 복귀: 중간 정지 제거 (2026-10-20)

`scripts/return_home.py`는 접히는 복귀 구간을 하나의 가감속 명령 스트림으로 실행한다.
Pick & Place의 자동 HOME 복귀와 메뉴의 HOME 복귀 모두 이 스크립트를 사용한다.

- 기존 `mid → 정지 확인 → P48에서 P32로 전환 → 재인계 → home` 절차를 제거했다.
- 출발 자세에서 선택한 P 게인(또는 명시한 P 값)을 HOME까지 유지한다. 종료 시 기존 게인 백업을 복원한다.
- 1600펄스를 넘는 복귀는 구간당 최대 1600펄스인 두 구간으로 계획하고, 중간점에서는 정지하지 않는다. 전체 상한은 3200펄스다. 기존 일반 이동의 1600펄스 상한은 그대로다.
- 전체 경로의 관절 범위·링크 높이를 명령 전 검사하고, 이동 중에도 현재 설정의 피드백·취소·시간 제한 검사를 유지한다.
- 접기 전 필요한 수직 상승과 출발 인계, HOME 도착 후 정지 확인·게인 복원은 유지한다.
- 속도, 틱 주기, HOME 값, 보정 파일, `guard_mode` 설정은 변경하지 않았다.

이 변경은 코드와 모의 시험으로 검증했으며 로봇을 구동하지 않았다.
P48을 유지한 채 접는 구간에서의 떨림·추종과 실제 연속 복귀는 실물 미검증이다.
