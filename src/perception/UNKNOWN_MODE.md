# unknown 자동 집기

물체 이름을 등록하지 않고, 시작 후 작업대에 새로 놓인 물체 하나를 `unknown`으로 선택한다.
기존 흰 상자·빨간 정육면체·줄자 메뉴는 유지한다.

## 사용

1. 카메라 미리보기 창을 닫고, 팔은 기존 메뉴가 요구하는 HOME 상태에서 시작한다.
2. 메뉴 **11번**으로 감지·계획만 먼저 확인한다. 놓을 칸은 1~3 중 선택한다(Enter=3).
3. `기준 저장 완료: 새 물체 하나를 놓고 손을 빼세요`가 나온 뒤 물체 하나를 놓는다. 기존 물체·카메라·트레이는 움직이지 않는다.
4. 90초 이내에 새 물체의 위치·높이·크기가 세 관측에서 안정되면 목표와 칸 위치를 출력한다. 11번은 로봇과 펌프를 열지 않는다.
5. 실제 동작 메뉴는 **10번**이다. 기존 실행 확인·토크 확인을 거치며, 실행 직전에 새 관측으로 물체 위치·크기·칸 상태를 다시 확인한다.

물체를 놓은 상태에서 시작하면 그 물체도 기준 장면에 포함되어 새 물체로 선택되지 않는다.
한 번에 한 작업을 수행한다. 다음 물체를 추가할 때 다시 메뉴를 선택한다.

## 초기 지원 범위

- 깊이 영상에서 보이는 높이 **20~45mm**, 보수적으로 추정한 가로·세로 **20~120mm**.
- 지름 20mm 이상의 평평한 윗면 패치가 관측되고, 수직 흡착 자세로 기존 작업 범위에 도달할 수 있어야 한다. 최초 후보가 부적합하면 다른 위치도 찾되, 실제 깊이의 편차 3mm·유효 영역 95% 기준은 유지한다.
- 주변 물체와 떨어져 있고 전체가 작업 영상 안에 보여야 한다. 기존 물체와 접촉·중첩되거나 함께 이동한 경우는 거부한다.
- 관측한 물체 외곽에 높이 오차를 반영하고 베이스 회전량만큼 돌려, 선택한 칸의 빈 바닥 경계와 5mm 이상 떨어지는지 확인한다. 칸 안에서 기존 놓기점의 20mm 이내를 탐색하며, 실행 직전에는 확정된 위치를 이동 없이 다시 검사한다. unknown은 수직으로 놓는다.
- 작은 깊이 잡음만 제외하며 실제 돌출물·깊이 누락·큰 구멍은 장애물로 유지한다. 칸을 확인할 수 없으면 거부한다.
- 천, 다공성·곡면·투명·강한 반사 물체 등의 흡착 가능성과 질량은 이 인식기로 판단할 수 없다.

색·종류 분류 대신 기준 깊이와 현재 깊이의 차이, 작업대 평면, 연결 영역을 사용한다.
흡착점이 물체 중심에서 벗어날 수 있으므로 운반 여유는 흡착점에서 가장 먼 외곽점을 포함하는 반경으로 계산한다.
기존 물체에서 얻은 눌림·접선 보정은 unknown에 적용하지 않는다. 관측한 윗면 높이를 접촉 후보로 쓰며,
놓기·벽 여유 계산에는 높이 불확실성 3mm를 더한다. 이 값은 현재 측정 모델의 가정이며 실측 보정 인증은 아니다.

## 실행 데이터와 검증

- 기준/선택 영상 및 관측값: `output/unknown_trials/`. 대기 실패 시 마지막 영상도 `failed_frame_*`로 저장한다.
- 동적으로 측정한 높이·크기·외곽 반경은 작업 JSON에 전달한다. 전역 `config/object_catalog.json`과 기존 보정 원본은 변경하지 않는다.
- 자동으로 계획한 뒤 위치·크기가 달라졌거나, 기준 파일이 바뀌었거나, 계획이 15초보다 오래되면 실행을 거부한다.
- `pick_unknown.py`는 기본적으로 계획만 수행한다. 실제 실행에는 `--execute --supported`가 필요하다.
- 동일한 저장 영상을 대상으로 집기를 반복하지 않도록 unknown은 1회 시도만 허용한다.
- 기존 `guard_mode`와 흡착/집힘 확인 설정은 변경하지 않았다. 압력 센서나 미등록 물체 전용 집힘 판정을 추가한 것은 아니다.

이번 추가 기능은 합성 깊이 영상, 실패 조건, 기존 메뉴 회귀, 실제 IK/운반 계획 드라이런으로 검증했다.
새 물체에 대한 깊이→실제 접촉 높이 정확도·흡착 성공률·실제 운반은 아직 실물 미검증이다.
