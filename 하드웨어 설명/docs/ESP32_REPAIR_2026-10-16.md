# ESP32 교체 후 펌프 복구

대상 보드 ESP32-D0WD-V3/MAC d0:ef:76:47:56:c0, CP2102_0001.
기존 4MB 플래시 전체를 output/esp32_repair/original_flash.bin에 보존했고 SHA256은 original_manifest.json에 기록했다.
기존 플래시에 알려진 펌프 흡착 ACK 문자열이 없었다(기존 프로그램의 정확한 종류는 미확정).

firmware/esp32_vacuum/esp32_vacuum.ino를 esp32:esp32:esp32로 컴파일·업로드했다.
모든 업로드 영역의 해시 검증 통과. GPIO26→A-1A/GPIO25→A-1B, USB115200,p/d/s,조회q.
서보 UART33/32 중계는 없음. 부팅 시 정지/배기300ms 후 자동 정지/흡착 ACK 유지.
업로드 후 식별·흡착 ACK·3초 명령·정지 ACK 확인. 사용자 "펌프 작동한다"로 실제 구동 확인.
압력·배관 방향·물체 들림은 별도 검증이다. 이 펌웨어는 흡착 유지 중 USB 리셋에 주의해야 한다.

검증: 펌프 관련18passed+12subtests. 전체 pytest는1011passed/3failed/5errors:
- test_servo_ros_adapter.py: ROS control_msgs 모듈 누락으로 초기화 테스트1실패/5오류.
- test_wrist_hand_eye.py: test_eye_in_hand_direction_recovered_and_holdout_checked 및
  test_no_independent_board_measurement_is_candidate_only는 cv2.calibrateHandEye 부재로 실패.
해당 실패 때문에 전체 테스트 통과로 보고하지 않는다.

실행 폴더는 /home/song/ros2_vacuum_pick_place_ver2로 변경되었다.
팔 USB 어댑터는 사용자 지정042407,기존 설정 백업 후 identity/port만 변경.
실행 옵션은 --travel-p48 --travel-rate150 --approach-tracking-limit100;
트레이 최대20mm 불확실성은 사용자가 명시적으로 허용했다.
